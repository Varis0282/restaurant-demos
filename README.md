# Restaurant Website Demos

Five complete, themed demo websites for one fictional restaurant (Zaika Veg Family Restaurant, Indore) — built with Next.js 14 + Tailwind.

- `/` — showcase landing (pick a design)
- `/thali` Classic Family · `/sizzle` Modern Animated · `/angan` Warm & Homely · `/velvet` Fine-Dining Dark · `/khata` Minimal Editorial
- Each theme: Home, About, Menu (60+ dishes with prices), Gallery, Contact + WhatsApp table booking, Hindi/English toggle, Indori specials section

**Rebrand for a client:** edit `lib/config.ts` (name, city, phone, WhatsApp, map).

```bash
npm install
npm run dev
```
